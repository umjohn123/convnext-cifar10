## 3. 首次运行结果（真实数据，非模拟）

| 项目 | 值 |
|---|---|
| 实验标签 | `mvp_atto_subset5k` |
| 存储位置 | `05_results/mvp_atto_subset5k/` |
| 算法 / 模型 | ConvNeXt（预设 `atto`，3,376,890 参数） |
| 数据规模 | 训练 4,500 / 验证 500 / 测试 2,000（快速验证子集，`is_full_scale = false`） |
| 训练配置 | AdamW(lr=2e-3, wd=0.05)、warmup 2 轮 + 余弦退火、batch 128、10 轮、seed 42、关闭 Mixup |
| 计算设备 | CPU（20 逻辑核） |
| **测试集 Top-1** | **45.05 %** |
| **测试集 Top-5** | **89.95 %** |
| 宏平均准确率 | 44.78 % |
| 最优验证准确率 | 45.20 %（epoch 10） |
| 总耗时 | 18 分 41 秒 |

**对照随机基线**（10 类）：Top-1 = 10 %、Top-5 = 50 %。
本次实验分别高出 **35.05 / 39.95 个百分点**，证明**整条流水线真实有效**。

**重要限定**：本轮为**刻意缩规模**的 MVP 实验（仅 4,500 张训练样本、10 轮），
目的是在无 GPU 环境下验证流程正确性；其准确率**不可**与全量数据结果或文献结果直接比较。
日志中已通过 `WARNING` 与结果文件中的 `is_full_scale: false` 双重标注。
